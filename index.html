What is an algorithm visualizer?

An algorithm visualizer turns abstract steps into a moving picture. Instead of reading pseudocode and imagining what happens, watch the data change in real time.

How to use these visualizers

  • Pick a category, then choose an algorithm.
  • Press play to watch it run, or step through one operation at a time.
  • Change the input and speed to test edge cases and build intuition.
